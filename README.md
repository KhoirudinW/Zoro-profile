# 🗡️ Zoro Profile

**Zoro Profile** is a modern profile website showcasing **Roronoa Zoro**, a character from the anime *One Piece*. This project was built as a hands-on learning exercise to strengthen my frontend development skills—particularly in combining **React**, **GSAP**, and **Tailwind CSS** to build a visually engaging and interactive web interface.

---

## 🧠 Inspiration & References

The design of the **hero section** was inspired by the clean, modern look of the [Zentry website](https://zentry.com). Development was guided by this helpful [YouTube tutorial](https://youtu.be/zA9r5zTllx4?si=qEDfVdBJIWE5pFMA), which provided insights on integrating **GSAP** animations within a React environment.

## ✨ Key Features

- 🎨 Modern & responsive UI design
- ⚡ Smooth interactive animations powered by **GSAP**
- 💨 Utility-first styling using **Tailwind CSS**
- ♻️ Reusable component structure with **React**

---

## 🛠️ Tech Stack

- **React.js** – For building dynamic and modular UI components  
- **GSAP (GreenSock Animation Platform)** – For smooth and engaging animations  
- **Tailwind CSS** – For efficient, utility-based styling  
- **Vite / Create React App** – (Depending on your setup, choose the appropriate bundler)

---

## 🎯 Project Goals

This project was created as part of my learning journey to:
- Design and build a visually appealing profile page
- Explore animation workflows using **GSAP** in **React**
- Practice clean and responsive layout building with **Tailwind CSS**
- Organize and scale component structures efficiently

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/username/zoro-profile.git

# Navigate into the project folder
cd zoro-profile

# Install dependencies
npm install

# Start the development server
npm run dev
