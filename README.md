# 🗡️ Zoro Profile

**Zoro Profile** adalah website profil modern untuk karakter **Roronoa Zoro** dari anime *One Piece*, dibuat sebagai proyek latihan untuk memperdalam pemahaman saya dalam frontend development, khususnya dalam menggabungkan **React**, **GSAP**, dan **Tailwind CSS**.

## ✨ Fitur Utama

- 🎨 Desain modern & responsif
- ⚡ Animasi interaktif menggunakan **GSAP**
- 💨 Styling cepat dan konsisten dengan **Tailwind CSS**
- 🔁 Struktur komponen reusable berbasis **React**

---

## 🛠️ Teknologi yang Digunakan

- **React.js** – Membangun UI dinamis dan modular
- **GSAP (GreenSock Animation Platform)** – Untuk animasi halus dan interaktif
- **Tailwind CSS** – Styling berbasis utility class
- **Vite / Create React App** – (pilih sesuai yang kamu pakai untuk inisialisasi proyek)

## 🎯 Tujuan Proyek

Proyek ini dibuat sebagai sarana belajar:
- Membuat website profil yang modern dan menarik
- Mengintegrasikan animasi dengan GSAP di dalam aplikasi React
- Membangun UI responsif dan bersih menggunakan Tailwind CSS
- Mengatur struktur proyek dan komponen yang rapi dan scalable
